// Tableau Build Guide
SF Initiatives Gantt
Replicate the HTML Gantt tracker exactly in Tableau · 3 phases · ~30 min
01
Connect the Excel file
Open Tableau → Connect → Microsoft Excel → select sf_gantt_tableau.xlsx → drag sheet Gantt_Data to the canvas.
Data Source tab
02
Verify date field types
In the Data Source view, check start_date and end_date both show a calendar icon. If they show as strings, click the icon → Change Data Type → Date.
Data Source tab → field headers
03
Create: Duration Days (calculated field)
Analysis → Create Calculated Field → name it Duration Days → enter formula:
[end_date] - [start_date]
Why: Tableau Gantt bars need a duration value on the Size shelf — not just start/end dates.
Analysis menu → Calculated Fields
04
Create: Progress Label
Create another calculated field named Progress Label:
STR(INT([progress_pct] * 100)) + "%"
Analysis menu → Calculated Fields
05
Create: Stage Color (optional but recommended)
If you want exact hex colors matching the HTML version, create a calculated field Stage Sort to control ordering:
IF [stage]='Acquisition' THEN 1
ELSEIF [stage]='Order Push' THEN 2
ELSEIF [stage]='COMMANDO' THEN 3
ELSE 4 END
Analysis menu → Calculated Fields
06
Set Mark type to Gantt Bar
Click the Marks card dropdown (default says "Automatic") → select Gantt Bar.
Marks card → type dropdown
07
Build the timeline axis (Columns)
Drag start_date to the Columns shelf. Right-click it → select Exact Date (not Year/Month truncation — this is critical for accurate bar positioning).
Columns shelf
Important: Must be Exact Date, not a truncated date part. Otherwise bars snap to month boundaries instead of exact days.
08
Build the row hierarchy (Rows)
Drag fields to the Rows shelf in this exact order — this creates the 3-level hierarchy matching the HTML version:
Rows project → sub_project → zone
Click the + icon next to each pill to expand the hierarchy level. This gives you Project → Sub-project → Zone (HN1, HN2 etc.) as collapsible rows.
Rows shelf
09
Set bar length (Size shelf)
Drag Duration Days (the calculated field from step 03) to the Size shelf on the Marks card.
Columns start_date (Exact)
Size Duration Days
Marks card → Size
10
Color bars by Stage
Drag stage to the Color shelf → click Color → Edit Colors → assign manually:
Acquisition → Amber
Order Push → Indigo
COMMANDO → Red
WP Cashback Trial → Amber
WP CB Customized → Orange
Launch → Green
Manual → Sky Blue
API → Purple
Marks card → Color
11
Add status border (Detail)
Drag status to the Detail shelf. Then click Color → Border → select a color dimension. This adds a subtle status-coded outline to each bar matching the HTML status colors.
Marks card → Detail, then Color → Border
12
Add progress label on bars
Drag Progress Label (calc field) to the Label shelf → click Label → set Alignment to center, Font size 8px white bold.
Marks card → Label
13
Add Today reference line
Open the Analytics pane (tab next to Data) → drag Reference Line onto the chart → select the date axis → set value to Today() → style: dotted, color indigo, label "Today".
Analytics pane → Reference Line
14

15
Add all filters
Drag each field to the Filters shelf. Right-click each filter → Show Filter to make it visible in the dashboard. Set each to multi-select checkbox (dropdown menu on filter → Multiple Values Dropdown or Checkbox).
project sub_project team city status priority start_date (Month/Year)
Month filter: Drag start_date to Filters → select Month / Year → tick "Show Filter" → right-click filter → Multiple Values (Checkbox) — this gives multi-select month exactly like the HTML version.
Filters shelf → Show Filter on each
16
Format the date axis
Right-click the x-axis → Format → Dates → Custom format: MMM YYYY for month headers. Set axis range: Fixed → 01/04/2025 to 31/12/2026.
X-axis → right-click → Format
17
Format row labels
Right-click the row headers → Format → Font size 10, Arial. Set row height: Format → Row Height → 28px. For the zone level, right-click → Format → set indent to show hierarchy visually.
Row headers → Format
18
Customise tooltip
Click Marks card → Tooltip → edit the template to match:
<Zone> · <Stage>
Status: <Status>
Progress: <progress_pct>
Team: <Team>
Dates: <start_date> → <end_date>
Note: <note>
Marks card → Tooltip
19
Add status summary bar chart (matches HTML status strip)
Create a new sheet → drag status to Columns, initiative_id (Count Distinct) to Rows → Marks = Bar → color by status → rename sheet "Status Summary". This will sit at the top of the dashboard like the HTML strip.
New sheet
20
Create new Dashboard
Dashboard menu → New Dashboard → set size to Fixed: 1400 × 900 (matches a widescreen laptop). Drag your Gantt sheet onto the canvas.
Dashboard tab
21
Layout: Status strip at top
Drag the Status Summary sheet to the top of the dashboard layout — set height to 80px. This matches the HTML status bar showing counts by status.
Dashboard layout panel
22
Layout: Filters on right panel
On the right side, add a Vertical Layout Container → drag the filter controls into it: Project, Sub-project, City, Team, Status, Month. Set container width to 220px. Title each filter with clean labels.
Dashboard → Layout → Containers
23
Apply filters across sheets
Click each filter control → dropdown → Apply to Worksheets → All Using This Data Source. This makes the filters affect both the Gantt and the Status Summary bar simultaneously.
Filter control → dropdown → Apply to Worksheets
24
Publish to Tableau Server or Public
Server → Publish Workbook (Tableau Server) or File → Save to Tableau Public. Share the URL with the team — anyone with the link can view and interact with all filters.
Server menu or Tableau Public
For stakeholder sharing: Tableau Public is free. Tableau Server requires a license but allows more control over permissions and live data refresh from Google Sheets.
// SF Initiatives — Update Workflow

Update via SeatTalk

Send a message to the bot → Gantt chart updates automatically on HTML & Tableau
Message format
Syntax — write in any natural order, Claude will parse it
update [INITIATIVE_ID or ZONE+STAGE] [PROGRESS%] [STATUS] [note: TEXT]
INITIATIVE_ID
The ID from the sheet e.g. PC_HN1_ACQ or shorthand like HN1 ACQ or HN1 acquisition
PROGRESS%
Any number 0–100 followed by % e.g. 60% or 60
STATUS
Any of the words below — Claude understands abbreviations and variations
note:
Optional freetext after note: — goes into the notes column e.g. note: blocked by vendor API
Status words (any variation works)
not-started · not started · planned in-progress · in progress · active · started on-track · on track · good · green at-risk · at risk · risk · yellow · caution delayed · delay · blocked · red · behind done · complete · completed · finished on-hold · paused · hold · pause

Setup steps
01
Create SeatTalk bot
SeatTalk Admin → Bots → Create Bot → name it SF Initiatives → get the webhook_url and bot_token. Set the bot's outgoing webhook to point to your n8n URL.
02
Import n8n workflow
n8n → Import → paste the contents of n8n_workflow.json. Set these environment variables:
ANTHROPIC_API_KEYyour Claude API key
SEATALK_WEBHOOK_URLfrom step 01
SHEET_IDGoogle Sheet ID from the URL
GANTT_URLyour GitHub Pages URL
03
Connect Google Sheet as Tableau data source
Tableau → Connect → Google Sheets → select your sheet → set extract to refresh every 1 hour. When the sheet updates, Tableau pulls it automatically. Publish to Tableau Server/Public for the team.
04
Host HTML Gantt on GitHub Pages
Push initiatives-gantt-v8.html to your GitHub repo → Settings → Pages → main branch. Share the URL. The HTML Gantt reads from localStorage — for team-shared updates, swap to fetch the Google Sheet JSON endpoint instead.
05
Add bot to your team SeatTalk group
Add SF Initiatives bot to your ops group. Anyone in the group can send update messages. The bot will reply with confirmation in the same thread. Pin the message format cheatsheet in the group description.
